## Страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | Главная, каталог, рекламные слайды, корзина, подбор/сравнение камер, «Моё устройство» и полноценный раздел Academy |

**Выбор моделей в каталоге:** `smart-hub-tray.css` и обновлённый
`smart-hub.js` — кнопки ⚖ работают как добавление/удаление из сравнения;
плавающая панель над мобильной навигацией показывает максимум три модели,
позволяет удалить одну или очистить всё и открывает сравнение только когда
выбрано как минимум две. Черновик выбора хранится в sessionStorage браузера,
без регистрации. Учитываются русский, английский, иврит и арабский.
Мобильный браузерный тест проверяет положение панели, накопление выбора,
открытие таблицы, удаление и очистку.

**Smart Hub:** `smart-hub.js` + `smart-hub.css` — три встроенных инструмента: подбор по реальным
характеристикам, сравнительная таблица до трёх устройств и сохранённая в браузере
модель с инструкцией, приложениями/обновлениями и учебной памяткой. Сопоставлять
можно восемь основных моделей с проверенными ключами `NEOLINE_DETAILS`; автоматически
импортированные товары без нормализованных характеристик в сравнение не включаются.
Демонстрационные цены/заказы не превращать в настоящие без подтверждения.

**NEOLINE Academy:** `neoline-academy.js` + `neoline-academy.css` — отдельный
легковесный раздел `#neolineAcademy`: 8 моделей, 4 темы (установка,
сопряжение, запись, обновления), по 3 шага, источники и приложения
от производителя. Видеокаталог существующий (`NEOLINE_PRODUCT_VIDEOS`),
загрузка внешнего плеера только после нажатия. Отметки «изучено» сохраняются
в браузере отдельно для каждой модели и темы, без аккаунта.
Раздел «Моё устройство» открывает обучение по сохранённой модели.
`NEOLINE_DEVICE_UPDATES.get(id)` возвращает проверенные метаданные страниц
европейской поддержки без прямых прошивок; в темах обновления предупреждаем
о несовместимости регионов и аппаратных модификаций.
`test-academy.yml` — настоящий мобильный Chromium с проверкой 4 языков,
RTL, источников, загрузки видео по нажатию и сохранения прогресса.

**Проверенный видеокаталог (20.11.2026):** `assets/catalog/tutorial-videos.json`
содержит только реально подтверждённые прямые YouTube-страницы.
Для Wowcam — два официальных русскоязычных ролика Neoline Россия по
подключению Android/iOS; для Wowcam и Flash 2K — общий обзор на польском.
В `catalog-video.js` добавлена отдельная подборка с указанием языка,
источника и категории, фильтры «все / подключение / обзор», проигрывание
только после нажатия. Для EN/HE/AR **не подставляется русский ролик как
основное видео**: вместо этого показывается поиск на языке сайта
(арабский — Израиль), а RU/PL-материалы открываются с честной маркировкой.
Если видео/доступ Facebook не подтверждены, не создаём фиктивных ссылок,
сохраняем `facebook-videos.json.videos=[]`.
Добавлена подтверждённая английская PDF Quick Start для Wowcam.
Из урока Academy `connect` открывается соответствующий видеокаталог
модели и фильтр инструкций. Старый каталог RUTUBE/VK сохранён.
`test-video-guides.yml` проверяет реальные идентификаторы, переключение
языков, отсутствие iframe до нажатия, загрузку и остановку видео,
совместимость с Academy и мобильный RTL.

**Обновления 20 ноября 2026:** Academy теперь проводит пользователя к
следующей ещё не изученной теме после отметки текущей и показывает
завершение 4/4 на всех четырёх языках. В импортированных товарных
фотогалереях доступны свайпы, синхронные миниатюры и доступные счётчики
фотографий; регрессия проверяется отдельным `test-catalog-gallery.yml`.

**Ежедневное задание в игре:** `teoria.js` + `teoria-daily.css`
добавляют компактный вызов под пятью существующими режимами.
Каждый день по часовому поясу `Asia/Jerusalem` формируется стабильный
набор из пяти вопросов государственного банка для выбранной категории
прав и языка, с тремя жизнями. После полного прохождения записывается
счётчик дней подряд, один раз за календарный день, только в
`localStorage`. При неудаче разрешён повтор тех же вопросов. Выполнение
отображается на русском, английском, иврите и арабском; результаты также
учитываются в истории обучения. Тесты `test-teoria.yml` проверяют
детерминированность вопросов, завершение и переход серии через полночь.

**Проверка публикации:** `verify-live.yml` теперь реально сравнивает
версионированные файлы каталога, Academy и игры с опубликованным Cloudflare,
а не старый шаблонный маркер HTML. Публикацию нельзя считать
подтверждённой, пока эта проверка не завершится успешно.

**Проверки:** `test-smart-hub.yml` — локальный Chromium на мобильной ширине,
`test-teoria.yml` — реальная игра RU/EN/HE/AR с проверкой официальных банков,
`test-teoria-ar.yml` — углублённый тест арабского, `test-news.yml` — новости и
показ фильтров доставки в актуальном модальном интерфейсе. Тесты не должны
полагаться на устаревшие селекторы или требовать немедленного Cloudflare деплоя.

Шапка общая: `site-header.css`, `site-header.js`, `assets/flag-israel.svg`.
Нижнее меню: `nav-current.css`, `nav-current.js`.

## Данные и автообновление

- Каталог: `assets/catalog/catalog.json`, `scripts/sync_catalog.py` и workflow `sync-catalog.yml`.
- Новости: `assets/news/news.json`, `scripts/sync_news.py`, `scripts/build_news_thumbnails.py`, workflow `sync-news.yml`.
- Точки доставки: `assets/pickup/points.json`, `scripts/sync_pickup_points.py`, workflow `sync-pickup-points.yml`.
- Магазины: `assets/retail/points.json`, `scripts/sync_retail_points.py`, workflow `sync-retail-points.yml`.
- Игра: `assets/teoria/{ru,he,en,ar}.json`, workflow `sync-teoria.yml`.
- Срочные события: данные полиции в отдельной ветке `traffic-live`, workflow `sync-traffic.yml`.

Карта отображает только доступные координаты OSM. Сведения о продавцах не подтверждают партнёрства.
График ДТП показывает **количество уникальных публикаций**, а не реальное число аварий. Не дополнять график страховыми данными без устойчивых идентификаторов происшествий.
Прозрачные фотографии `assets/transparent/` — используемые изображения, не удалять.

## Обслуживание

1. Перед удалением файлов создавать отдельную резервную ветку из актуального `main`.
2. Не удалять картинки `assets/catalog/images/` и `assets/news/images/` по совпадающему хешу: все текущие пути используются в JSON. Если внедряется дедупликация — обновлять и генератор, и манифест одновременно.
3. При изменениях проверять `node --check` для JS, ссылки на ассеты и GitHub Actions. Обновлять параметр `?v=` у изменённых ресурсов для сброса кеша Cloudflare.
4. Публичную публикацию Cloudflare подтверждать отдельно; коммит в GitHub не доказывает, что новая версия уже доступна на сайте.

Хронология предыдущих итераций, включая оригинальные пробные файлы и
`CURRENT_TASK.md`, доступна в восстановительной истории. Удалена только
неиспользуемая `teoria-traffic-signs.css` (была заменена новым оформлением).
Одноразовый скрипт очистки старых веток удалён после успешного исполнения.
