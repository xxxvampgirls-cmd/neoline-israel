**Выбор моделей в каталоге:** `smart-hub-tray.css` и обновлённый
`smart-hub.js` — кнопки ⚖ работают как добавление/удаление из сравнения;
плавающая панель над мобильной навигацией показывает максимум три модели,
позволяет удалить одну или очистить всё и открывает сравнение только когда
выбрано как минимум две. Черновик выбора хранится в sessionStorage браузера,
без регистрации. Учитываются русский, английский, иврит и арабский.
Мобильный браузерный тест проверяет положение панели, накопление выбора,
открытие таблицы, удаление и очистку.

**Smart Hub:** `smart-hub.js` + `smart-hub.css` — три встроенных инструмента: подбор по реальным
характеристикам, сравнительная таблица до трёх устройств и сохранённая в браузере
модель с инструкцией, приложениями/обновлениями и учебной памяткой. Сопоставлять
можно восемь основных моделей с проверенными ключами `NEOLINE_DETAILS`; автоматически
импортированные товары без нормализованных характеристик в сравнение не включаются.
Демонстрационные цены/заказы не превращать в настоящие без подтверждения.

**NEOLINE Academy:** `neoline-academy.js` + `neoline-academy.css` — отдельный
легковесный раздел `#neolineAcademy`: 8 моделей, 4 темы (установка,
сопряжение, запись, обновления), по 3 шага, источники и приложения
от производителя. Видеокаталог существующий (`NEOLINE_PRODUCT_VIDEOS`),
загрузка внешнего плеера только после нажатия. Отметки «изучено» сохраняются
в браузере отдельно для каждой модели и темы, без аккаунта.
Раздел «Моё устройство» открывает обучение по сохранённой модели.
`NEOLINE_DEVICE_UPDATES.get(id)` возвращает проверенные метаданные страниц
европейской поддержки без прямых прошивок; в темах обновления предупреждаем
о несовместимости регионов и аппаратных модификаций.
`test-academy.yml` — настоящий мобильный Chromium с проверкой 4 языков,
RTL, источников, загрузки видео по нажатию и сохранения прогресса.

**Ежедневное задание в игре:** `teoria.js` + `teoria-daily.css`
выводят компактную карточку «Задание дня» **между верхней панелью статистики и выбором режимов**. Карточка переносится за пределы `#gameLobby`, не дублируется внизу и скрывается на время игры. Дизайн — спокойный бело-голубой, с сохранением мобильной адаптации и RTL.

детерминированность вопросов, завершение, сохранение серии, расположение карточки над режимами, мобильные размеры, скрытие карточки во время игры.

## Обслуживание

1. Перед удалением файлов создавать отдельную резервную ветку из актуального `main`.
2. Не удалять картинки `assets/catalog/images/` и `assets/news/images/` по совпадающему хешу: все текущие пути используются в JSON. Если внедряется дедупликация — обновлять и генератор, и манифест одновременно.
3. При изменениях проверять `node --check` для JS, ссылки на ассеты и GitHub Actions. Обновлять параметр `?v=` у изменённых ресурсов для сброса кеша Cloudflare.
4. Публичную публикацию Cloudflare подтверждать отдельно; коммит в GitHub не доказывает, что новая версия уже доступна на сайте.

Хронология предыдущих итераций, включая оригинальные пробные файлы и
`CURRENT_TASK.md`, доступна в восстановительной истории. Удалена только
неиспользуемая `teoria-traffic-signs.css` (была заменена новым оформлением).
Одноразовый скрипт очистки старых веток удалён после успешного исполнения.
