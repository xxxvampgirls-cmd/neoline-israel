# NEOLINE Israel: автоновости — фото и генерация

## Без API-ключей
- Автоматически подбираются реальные лицензированные фотоснимки по автомобильной тематике из Wikimedia Commons (не фотографии описываемых событий).
- Миниатюры готовятся в WebP 640×360 и меньше 90 КБ. Сохраняются указание источника фото и авторство.
- Одна картинка используется в RU, HE, EN, AR. Заголовок накладывается отдельным HTML на выбранном языке.
- Лента выводит девять карточек и догружает следующую порцию при прокрутке. Браузер лениво загружает картинки.
- Статьи и картинки хранятся до 30 дней, старые удаляются при синхронизации.

## AI-миниатюры (опционально, отдельная оплата)
Готовый механизм `scripts/build_news_thumbnails.py` поддерживает OpenAI Images API. Для включения владелец репозитория самостоятельно добавляет `OPENAI_API_KEY` в GitHub → Settings → Secrets and variables → Actions → New repository secret. Нельзя помещать ключ в код или чат.

До 2 новых AI-изображений за запуск; количество ограничивает `MAX_AI_PER_RUN`. По умолчанию вызывается `gpt-image-1-mini`; перед платным включением проверить, доступна ли модель и устраивает ли стоимость. Без ключа механизм НЕ делает платных запросов, используются бесплатные лицензированные фотографии.

AI-фон — обобщённая стилизованная редакционная сцена, не «подлинное фото ДТП». Карточка помечает генерацию. Никаких лиц пострадавших, брендов или вымышленных деталей происшествия.

## Проверка
`assets/news/image-report.json` — размер, источники и число фотографий; `assets/news/sync-report.json` — источники и охват. `.github/workflows/test-news.yml` проверяет опубликованный сайт, языки, 30 дней, ссылки, миниатюры и подгрузку.

Не обещать полного покрытия всех изданий: часть RSS ограничивает доступ, а лента накапливает актуальные публикации по мере ежедневного обновления.
