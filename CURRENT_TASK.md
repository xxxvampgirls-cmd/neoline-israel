# NEOLINE Israel — текущая задача: полный каталог из neoline.ru/shop/

Актуальный запрос (16.11.2026): дополнить наш демонстрационный каталог ВСЕМИ товарами действующего русского интернет-магазина NEOLINE с обработанными фотографиями и подробными описаниями/техническими характеристиками.

## Выполнено и проверено в GitHub
- Настроен загрузчик `scripts/sync_catalog.py` из публичного `https://neoline.ru/shop/` и категорий сайта. Каждая новая модель имеет ссылку на исходную страницу производителя.
- Импортируются карточки по всем основным категориям: гибриды, видеорегистраторы, радар-детекторы, аксессуары, акустика, уценка.
- Из исходных страниц извлекаются характеристики таблиц и списков; описания ограничены короткими выдержками/фактическими сводками вместо копирования целиком рекламного текста. Отсутствующие характеристики не придумываются.
- Фотографии скачиваются в `assets/catalog/images`, нормализуются по размеру и весу. Прозрачность фона создаётся только при уверенно белом исходном фоне; иначе исходное содержимое сохраняется.
- Файл `assets/catalog/catalog.json` и `assets/catalog/sync-report.json` созданы успешным GitHub Actions; первый подтверждённый импорт (54 товара, 162 картинки, 40 карточек с распознанными характеристиками; остальные требуют уточнения деталей у производителя).
- `catalog-ui.js` / `catalog-ui.css` подключены к `index.html`: новые категории и карточки, фото, описания и характеристики, ссылки на первоисточник, поиск, фильтрация, выбор языка UI. Первоначальные восемь демонстрационных моделей сохранены, совпадающие записи не повторяются.
- Для новых моделей цены в Израиле **не придуманы**: написано «Цена в Израиле уточняется», кнопка добавления таких позиций в корзину не показывается. Цены и доступность требуют отдельного подтверждения.
- Настроена еженедельная синхронизация источника через GitHub Actions (а также ручной запуск). Архивный раздел производителя не включён в этот импорт без дополнительного решения.
- Прежнее утверждённое оформление: логотип без звезды Давида; рекламные голубые полосы, мягкие тени и приближение товара оставлены.

# NEOLINE Israel — текущая задача (16.11.2026)

## Единственная активная задача
Завершить исправление логотипа NEOLINE на сайте: только знак N и надпись NEOLINE, без подписи и без отдельной звезды Давида.

## Требования
- Использовать подлинный логотип NEOLINE из проверенного официального источника, без имитации шрифта или генерации.
- Сделать знак и фирменное написание читаемыми на телефоне и компьютере, без обрезанных букв, искажений и серого фона.
- По последнему указанию пользователя звезда Давида убрана из фирменного блока в шапке и подвале и из декоративных элементов сайта. Национальный флаг на кнопке переключения на иврит сохранён как элемент выбора языка.
- Аккуратно выровнять логотип и переключатель языков на мобильных экранах.
- Проверить фактическое отображение на опубликованном сайте. Коммит в GitHub сам по себе не подтверждает публикацию Cloudflare или внешний вид.

## Что сейчас НЕ входит в задачу
- Фото товаров, удаление фона, галереи, запасные изображения.
- Каталог, характеристики, рекламные блоки, корзина и другие элементы.
- Любые новые функции, не обсуждавшиеся пользователем.

## Правило работы
Перед изменением сверяться с этой записью. Исправлять только логотип и непосредственно запрошенные элементы оформления; не переключаться на другие задачи без нового явного запроса пользователя.
В отчёте разделять подтверждённые изменения кода и проверенное отображение на опубликованном сайте. Не выдавать планы за выполненные работы.
